# Erro de Cursor Invisível/Branco no Google Docs

## Descrição do Problema
O cursor de seleção de texto fica totalmente branco ou invisível ao utilizar o Google Docs. Isso ocorre devido a um conflito de renderização do navegador com as configurações de ponteiro do sistema operacional.

## Como Resolver

### Ajustar as Propriedades do Mouse (Windows)
Siga o passo a passo abaixo para restaurar a visibilidade do cursor:

1. **Abrir as Configurações do Mouse:** Pressione as teclas `Windows + R`, digite `main.cpl` e aperte **Enter**.
2. **Acessar a Aba Correta:** Clique na aba **Ponteiros** na janela que se abriu.
3. **Selecionar a Função:** Na lista de esquemas, selecione a opção **Seleção de texto**.
4. **Alterar o Cursor:** Clique no botão **Procurar**, selecione um cursor padrão alternativo (como o `beam_r.cur`) e clique em **Abrir**.
5. **Aplicar Mudanças:** Clique em **Aplicar** e depois em **OK**.
