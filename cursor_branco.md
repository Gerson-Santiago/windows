# Tutorial de Configuração

### Passo 1: Abrir o Executar
Pressione as teclas `Windows + R` no seu teclado.

---

### Passo 2: Comando do Sistema
Digite o comando abaixo na caixa de diálogo que apareceu:

```bash
main.cpl
```

---

### Passo 3: Finalizar
Aperte **Enter** para abrir as propriedades do mouse.
